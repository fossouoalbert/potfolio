# Portfolio de FOSSOUO SILATCHOM Yann Albert

Bienvenue sur mon portfolio personnel. Ce projet me permet de présenter qui je suis, mes compétences, mes projets et les moyens de me contacter.

## À propos

Je suis un développeur web passionné par la création de sites et d'applications modernes, fonctionnels et bien conçus. Ce portfolio a été réalisé pour montrer mon parcours, mes compétences techniques et mes réalisations.

## Objectif du projet

Le but de ce site est de :

- présenter mon profil professionnel;
- partager mes compétences en développement web;
- mettre en avant mes projets réalisés;
- donner un accès rapide à mon CV et à mes réseaux sociaux;
- permettre à des recruteurs ou clients de me contacter facilement.

## Fonctionnalités

- page d'accueil avec présentation personnelle;

## Comment voir le projet

1. Téléchargez ou clonez ce projet.
2. Ouvrez le fichier `index.html` dans votre navigateur.
3. Vous pouvez aussi utiliser un serveur local pour une meilleure expérience.

### Option recommandée

Avec VS Code, vous pouvez utiliser l'extension Live Server pour ouvrir le site plus facilement.
